✨ Features (raw list)

🎯

New uploads only

First add grabs the latest video; old ones are marked seen forever. Every check downloads just fresh uploads — even if you delete files.

🎬

Videos + Shorts scopes

Channel link monitors both; a shorts link watches shorts only; a video link watches videos only.

🛡️

YouTube bot-wall bypass

Auto / Direct / PO-Token methods, bundled JS solver, cookies + proxy support with IP-change guidance.

⚙️

Thread pool 1–10

Parallel profiles with live progress bars, plus an auto calculator (CPU/RAM/net bottleneck).

🍪

Cookies manager

Paste browser cookies per site, per-site status (Ready/Login missing/Expired), live validity test.

🔔

Notifications + logs

Bell with unread count, NEW pills, in-app log viewer with error filter, download & clear.

📁

Your folders

Global root + per-profile folder, native folder picker, free-space display, platform/creator layout.

🌐

4 languages + themes

English, Roman Urdu, Español, 中文 with one-click toggle; dark/light mode, mobile responsive.

⬆️

Self-updating

App + yt-dlp/gallery-dl engines update from inside the app; releases built automatically.

🚀 Get it in 2 minutes

1. Download the Setup (Windows) or tarball (Linux).
2. Install & launch — paste a channel link, pick a folder, done. First video downloads instantly.
3. For Instagram/X: import login cookies on the 🍪 page. For YouTube walls: Updates → Setup YouTube.
